# Third-party components

FrameForge uses components from other projects. Their authors retain their rights, and their original licenses apply independently of the FrameForge application terms.

The Free catalog offers RIFE 4.6 and Real-ESRGAN via their NCNN/Vulkan packages. The desktop runtime also includes Python, Qt/PySide6/Shiboken6, FFmpeg, Pillow, psutil, imageio-ffmpeg and supporting libraries. Model downloads have their own notices and license confirmation.

The release documentation ZIP contains application terms in six languages, build notices, available library license texts and the dependency inventory. The installed application also includes a licenses folder. These license texts and upstream links do not themselves replace required corresponding-source delivery.

Qt/PySide6 libraries are dynamically loaded, and the installation does not prevent replacing them with compatible modified versions. FFmpeg runs separately. See the build notices for paths and replacement instructions. Third-party license rights take precedence over conflicting application restrictions.
