# Support

Report reproducible bugs through the issue form, or contact **iheel.support@gmail.com**. Include the app version and edition, Windows version, GPU and driver, model, settings, source resolution/FPS and exact error text. Say whether clip selection or block processing was enabled.

Remove personal folder names and other private information from logs and screenshots. Do not post private videos, account credentials or payment details. There is no promised response-time SLA.

For sensitive security reports, use the support email instead of a public issue. To follow development or explore the full edition: https://www.patreon.com/c/iHeel.
